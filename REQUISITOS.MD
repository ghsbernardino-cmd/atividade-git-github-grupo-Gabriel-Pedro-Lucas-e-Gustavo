## Requisiyos funcionais 
* exibir um menu textual no terminal 
* o sistema deve permitir a inserção de um novo aluno coletando obrigatoriamente tres informações: Nome, Idade e turma

## Requisitos Não Funcionais 
* sem dependencias externas. O sistema deve rodar utilizando apenas os recursos nativos 
* Os dados devem ser mantidos de forma volátil durante a execução. O encerramento do programa causará a perda dos dados cadastrados.
